Leçon 1.1 : Qu'est-ce que le HTML ?

HTML (HyperText Markup Language) est le langage de balisage standard utilisé pour créer des pages web.

Points clés :

  • HTML n'est pas un langage de programmation, c'est un langage de balisage
  • Il utilise des balises pour définir la structure du contenu
  • Il est interprété par les navigateurs web
  • HTML5 est la dernière version (publiée en 2014)

Pourquoi apprendre HTML ?

  • C'est la base de tout site web
  • Indispensable pour le développement web
  • Facile à apprendre pour les débutants

Leçon 1.2 : Structure d'un document HTML

Tout document HTML a une structure de base :

<!DOCTYPE html>
<html>
  <head>
    <title>Titre de la page</title>
  </head>
  <body>
    <!-- Contenu de la page -->
  </body>
</html>

Explication des balises :

  • <!DOCTYPE html> : Déclare le type de document (HTML5)
  • <html> : Élément racine du document
  • <head> : Contient les métadonnées (titre, styles, scripts)
  • <title> : Titre affiché dans l'onglet du navigateur
  • <body> : Contenu visible de la page

Leçon 1.3 : Votre première page HTML

Créons votre première page avec du texte et des titres :

<!DOCTYPE html>
<html>
  <head>
    <title>Ma première page</title>
  </head>
  <body>
    <h1>Bienvenue sur mon site !</h1>
    <p>Ceci est mon premier paragraphe.</p>
    <p>HTML est facile à apprendre !</p>
  </body>
</html>

Les balises de titres :

  • <h1> : Titre principal (plus important)
  • <h2> : Sous-titre
  • <h3> : Sous-sous-titre
  • <h4>, <h5>, <h6> : Titres de moindre importance

Exercice 1 : Créez votre page personnelle

Créez une page HTML avec :

  • Votre nom dans un titre h1
  • Une courte bio dans un paragraphe
  • Vos hobbies dans une liste
<!DOCTYPE html>
<html>
  <head>
    <title>Ma page personnelle</title>
  </head>
  <body>
    <h1>Votre Nom</h1>
    <p>Votre bio courte ici...</p>
    <h2>Mes hobbies</h2>
    <p>Vos hobbies ici...</p>
  </body>
</html>
