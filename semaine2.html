Leçon 2.1 : Les balises de texte

Découvrons les balises essentielles pour formater le texte :

Paragraphe et sauts de ligne :

<p>Ceci est un paragraphe.</p>
<p>Ceci est un autre paragraphe.</p>
<br> <!-- Saut de ligne -->

Mise en forme du texte :

<strong>Texte important (gras)</strong>
<em>Texte emphatique (italique)</em>
<mark>Texte surligné</mark>
<del>Texte barré</del>
<ins>Texte inséré</ins>
<sub>Indice</sub>
<sup>Exposant</sup>

Ligne horizontale :

<hr> <!-- Ligne horizontale -->

Leçon 2.2 : Les listes

HTML propose deux types de listes :

Liste non ordonnée (puces) :

<ul>
  <li>Premier élément</li>
  <li>Deuxième élément</li>
  <li>Troisième élément</li>
</ul>

Liste ordonnée (numéros) :

<ol>
  <li>Première étape</li>
  <li>Deuxième étape</li>
  <li>Troisième étape</li>
</ol>

Exercice 2 : Créez des listes

Créez une page HTML avec :

  • Une liste non ordonnée de vos 3 films préférés
  • Une liste ordonnée de vos 3 livres préférés
<!DOCTYPE html>
<html>
  <head>
    <title>Mes préférences</title>
  </head>
  <body>
    <h1>Mes films préférés</h1>
    <ul>
      <li>Film 1</li>
      <li>Film 2</li>
      <li>Film 3</li>
    </ul>

    <h1>Mes livres préférés</h1>
    <ol>
      <li>Livre 1</li>
      <li>Livre 2</li>
      <li>Livre 3</li>
    </ol>
  </body>
</html>

Leçon 2.3 : Les liens et les images

Les liens (balise a) :

<a href="https://www.example.com">Lien vers un site</a>
<a href="page2.html">Lien vers une page locale</a>
<a href="#section">Lien vers une ancre</a>
<a href="mailto:email@example.com">Envoyer un email</a>
<a href="tel:+33612345678">Appeler</a>

Les images (balise img) :

<img src="image.jpg" alt="Description de l'image">
<img src="https://example.com/image.png" alt="Image externe">

Attributs importants pour img :

  • src : Chemin de l'image (obligatoire)
  • alt : Texte alternatif (obligatoire pour l'accessibilité)
  • width : Largeur en pixels
  • height : Hauteur en pixels
