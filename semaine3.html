Leçon 3.1 : Introduction aux formulaires

Les formulaires permettent aux utilisateurs d'entrer des données. La balise principale est <form>.

Structure de base :

<form action="/submit" method="POST">
  <!-- Champs du formulaire -->
</form>

Attributs importants de form :

  • action : URL où les données sont envoyées
  • method : Méthode HTTP (GET ou POST)

Éléments de formulaire :

<label for="nom">Nom :</label>
<input type="text" id="nom" name="nom">

Types d'input courants :

  • text : Champ de texte
  • email : Adresse email
  • password : Mot de passe (caractères masqués)
  • number : Nombre
  • date : Date
  • checkbox : Case à cocher
  • radio : Bouton radio
  • file : Fichier
  • submit : Bouton d'envoi

Leçon 3.2 : Créer un formulaire complet

<form action="/submit" method="POST">
  <div>
    <label for="nom">Nom :</label>
    <input type="text" id="nom" name="nom" required>
  </div>

  <div>
    <label for="email">Email :</label>
    <input type="email" id="email" name="email" required>
  </div>

  <div>
    <label for="message">Message :</label>
    <textarea id="message" name="message" rows="4"></textarea>
  </div>

  <div>
    <label>
      <input type="checkbox" name="newsletter">
      S'abonner à la newsletter
    </label>
  </div>

  <button type="submit">Envoyer</button>
</form>

Exercice 3 : Formulaire de contact

Créez un formulaire de contact avec :

  • Champ nom (text, obligatoire)
  • Champ email (email, obligatoire)
  • Champ message (textarea)
  • Bouton d'envoi

Leçon 3.3 : Médias et iframes

Vidéos (balise video) :

<video width="320" height="240" controls>
  <source src="video.mp4" type="video/mp4">
  Votre navigateur ne supporte pas la vidéo.
</video>

Audio (balise audio) :

<audio controls>
  <source src="audio.mp3" type="audio/mpeg">
  Votre navigateur ne supporte pas l'audio.
</audio>

Iframes (contenu externe) :

<!-- YouTube -->
<iframe width="560" height="315"
  src="https://www.youtube.com/embed/VIDEO_ID"
  frameborder="0"
  allowfullscreen>
</iframe>

<!-- Google Maps -->
<iframe
  src="https://www.google.com/maps/embed?pb=..."
  width="600" height="450"
  frameborder="0"
  allowfullscreen>
</iframe>

Attributs utiles pour iframe :

  • width : Largeur
  • height : Hauteur
  • frameborder : Bordure (0 = aucune)
  • allowfullscreen : Permettre le plein écran
